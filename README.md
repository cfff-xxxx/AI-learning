# AI Learning Journey

这个仓库记录了我从零开始学习 AI 应用开发的完整历程。

## 📂 项目结构
- `python_projects/week1_llm_basics/`: LLM 基础、多轮对话、LLM-as-a-Judge 自动化评估脚本
- `python_projects/week2_paper_summarizer/`: 基于 LLM 的学术论文智能总结工具

## 🛠️ 技术栈
- Python 3.11, OpenAI SDK, DeepSeek API
- 虚拟环境管理 (.venv), 环境变量管理 (.env)
- Git 版本控制

## 🚀 核心亮点
- 掌握了 Prompt Engineering 和 Context 管理
- 实现了基于 pdfplumber 的 PDF 解析
- 独立设计并实现了 LLM-as-a-Judge 自动化评估流水线，对 AI 输出进行质量检测（AI 测试开发核心能力）
